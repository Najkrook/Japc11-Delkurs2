# 09 — Köp en silverbelöning som recept eller variant

**What to build:** Studenten kan köpa och återfinna en recept- eller variantbelöning efter en silvermedalj, vilket ger synlig menyvariation utan ett separat system för manuellt menyval.

**Blocked by:** 06 — Köp den första förbättringen efter kapitel 6-brons

**Status:** done

- [x] Minst en uttryckligt vald provisorisk recept- eller variantbelöning kopplas till rätt kapitels silverupplåsning och visar begripligt krav, pris och ägandestatus i butiken.
- [x] Belöningen köps med det befintliga servervaliderade köpflödet och hämtade yen. Upplåsning, köp och visning är åtskilda; upprepade anrop ger inte dubbla köp.
- [x] Den ägda belöningen syns i restaurangens meny- eller föremålsvisning och bevaras efter omladdning och kontobyte.
- [x] Eventuell effekt på intäkt per beställning följer den uttryckligt valda katalogeffekten och bokföringspolicyn i 01. Saknas beslutad ekonomisk effekt förblir belöningen visuell.
- [x] Ingen manuell receptmeny, råvarulagring eller ny produktionsflaskhals införs. Tester verifierar silverkrav, köp, beständig visning och eventuell beslutad intäktseffekt.
