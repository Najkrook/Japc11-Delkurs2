# 07 — Köp och installera transportbandet från kapitel 9

**What to build:** Studenten kan köpa ett transportband efter kapitel 9-brons och se det på sin förutbestämda plats. Installationen förbättrar servicekapaciteten och ger en tydlig visuell milstolpe.

**Blocked by:** 06 — Köp den första förbättringen efter kapitel 6-brons

**Status:** done

- [x] Den permanenta upplåsningen för kapitel 9-brons öppnar transportbandet och rätt studiekrav visas. Tester använder kapitlets lektionsnummer och verifierar kopplingen till week-4.
- [x] Transportbandet köps genom det servervaliderade köpflödet för katalogens pris. Det är en enda fördefinierad installation med beständigt ägande och kan inte köpas dubbelt.
- [x] Bandet höjer servicekapaciteten enligt katalogen. Förhandsvisning och utfall visar faktisk intäktseffekt när köket respektive servicen begränsar produktionen.
- [x] Scenen visar bandet på dess fasta plats både direkt efter köp och efter omladdning. Ingen konstruktion, segmentplacering eller banredigering införs.
- [x] Köp under en pågående eller full intäktsperiod följer 01. Tester täcker rätt/fel kapitelbehörighet, debitering en gång, kapacitetseffekt och den synliga installationen.
